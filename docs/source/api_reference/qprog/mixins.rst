Mixins
======

Each mixin adds one orthogonal capability to a
:class:`~divi.qprog.QuantumProgram` subclass: observable-measurement
configuration, discrete-solution sampling, a classical data axis, or a
layered-ansatz circuit. :class:`~divi.qprog.mixins.SolutionEntry` is the uniform
return type for decoded solutions.
